BASIC

論理回路は「0 と 1 だけの世界」

コンピュータの中では、すべての情報が 0 と 1 で表されます。 電気が流れていない状態が 0、流れている状態が 1 です。 その 0 と 1 を受け取って、決まった規則で新しい 0 か 1 を出すのが論理ゲートです。

ゲートは全部で数種類しかなく、やっていることは「決まった表のとおりに答えを返す」だけです。 難しそうな名前がついていますが、覚えることは多くありません。

基本は3つ。あとはその組み合わせ

ゲート 1 になる条件 日本語で言うと
AND 両方とも 1 のとき A かつ B
OR どちらか一方でも 1 のとき A または B
NOT 入力が 0 のとき A でない
XOR 2つが違う値のとき どちらか一方だけ
NAND AND の答えを逆にしたもの AND でない
NOR OR の答えを逆にしたもの OR でない
頭に N がついたら「反転」です。 NAND は AND の、NOR は OR の答えをひっくり返しただけです。 この2つを別々に暗記する必要はありません。 AND と OR を求めてから、最後に 0 と 1 を入れ替えれば済みます。

TRUTH TABLE

真理値表は「全部書き出す」ための表

真理値表は、入力の組み合わせをすべて並べて、出力を1つずつ確かめる表です。 組み合わせの数は決まっていて、入力が増えるたびに2倍になります。

入力の数組み合わせ表の行数
1つ0, 12行
2つ00, 01, 10, 114行
3つ000 〜 1118行

たった4行か8行しかありません。 頭の中だけで「AかつBでないとき…」と考えるより、表を書いたほうが速く、確実です。 上のシミュレーターでも、入力を切り替えると今どの行にいるのかが色でわかるようになっています。

AND と OR の真理値表

AB ANDORXOR
00000
01011
10011
11110
XOR だけ、いちばん下の行が 0 です。 OR は「どちらか一方でも 1 なら 1」ですが、XOR は「どちらか一方だけが 1 のとき 1」です。 両方 1 のときの扱いが違う——ここが OR と XOR を見分けるポイントになります。

LINK

プログラムの条件分岐とまったく同じ

論理回路は特別な話ではありません。 第3問で出てくる条件式と、やっていることは同じです。

回路 プログラム表記 Python JavaScript
AND A かつ B a and b a && b
OR A または B a or b a || b
NOT A でない not a !a

たとえば 集計する処理 の例題で出てきた次の条件は、AND ゲートそのものです。 

もし Nums[i] ％ 3 == 2 かつ Nums[i] > 10 ならば:
⎿ count = count + 1

「3で割った余りが2」を A、「10より大きい」を B と置けば、 A AND B が 1 のときだけ中身が実行されるという形です。 条件が3つ4つと増えても考え方は変わらず、真理値表を書けば必ず整理できます。

条件式で迷ったら、0 と 1 に置き換えてください。 「成り立つ＝1」「成り立たない＝0」とすれば、複雑な条件も上の表と同じ話になります。 繰り返しを抜ける条件 や シミュレーション型の打ち切り条件 でも、この読み替えが効きます。

DE MORGAN

「かつ」の否定は「または」になる

条件をひっくり返すとき、多くの人がつまずきます。 「A かつ B」でない——これを言い換えると、どうなるでしょうか。

「A でない かつ B でない」と考えたくなりますが、これは誤りです。 正しくは次のようになります。 

NOT(A かつ B) ＝ (NOT A) または (NOT B)
NOT(A または B) ＝ (NOT A) かつ (NOT B)

否定すると、「かつ」と「または」が入れ替わります。 これをド・モルガンの法則と呼びます。 覚えにくければ、真理値表で確かめれば済みます。

AB A かつ B NOT(A かつ B) (NOT A) または (NOT B)
00011
01011
10011
11100

右の2列が4行とも同じです。だから入れ替えて書いても構いません。 シミュレーターで NAND を選んだときの出力と、 この NOT(A かつ B) の列を見比べると、まったく同じだと分かります。

これは条件分岐で実際に使います。 たとえば「点数が60以上 かつ 出席が8回以上のとき合格」という条件があるとき、 不合格の条件は「点数が60未満 または 出席が8回未満」です。 「かつ」のまま否定すると、両方を満たさない人だけが不合格になってしまい、答えがずれます。

EXERCISE 1

例題1：出力が 1 になる組み合わせを数える

次の回路で、出力が 1 になる入力の組み合わせはいくつありますか。 

出力 ＝ (A AND B) OR (NOT C)

選択肢：① 3個　② 4個　③ 5個　④ 6個

答えと解説を見る

答え：③ 5個

入力が3つなので、組み合わせは 8通りです。 数える方法は1つだけ——8行すべて書き出すことです。 途中を飛ばして考えると、必ずどこかを取りこぼします。

ABC A AND BNOT C出力
000011
001000
010011
011000
100011
101000
110111
111101

出力が 1 の行は 5行です。

表をよく見ると、C が 0 の行はすべて出力が 1 になっています。 NOT C が 1 になり、OR は片方が 1 なら 1 だからです。 C が 0 の行は4つ、残りは A AND B が 1 になる 1 行だけ——合わせて5行、と数えることもできます。

上のシミュレーターで確かめられます。 「組み合わせ」を選び、①に AND、②に NOT、③に OR を設定してから、 真理値表のタブを開いてみてください。同じ表が出ます。

EXERCISE 2

例題2：条件をひっくり返す

次の条件を、「かつ」を使わずに書き直したものとして正しいものを選びなさい。 

NOT(A かつ B)

選択肢：① (NOT A) または (NOT B)　② (NOT A) かつ (NOT B) ③ NOT(A または B)　④ A または B

答えと解説を見る

答え：① (NOT A) または (NOT B)

ド・モルガンの法則です。否定を中に入れると、「かつ」は「または」に変わります。

意味で考えると分かりやすくなります。 「両方とも成り立つ」の否定は、「少なくとも一方は成り立たない」です。 片方だけ崩れていれば、もう「両方」ではなくなるからです。

  • ② (NOT A) かつ (NOT B) … 「両方とも成り立たない」という意味になり、条件が厳しすぎます。 A だけが成り立っている場合を取りこぼします。最も選ばれやすい誤答です
  • ③ NOT(A または B) … これは②と同じ意味です（もう一方のド・モルガンの法則）。やはり厳しすぎます
  • ④ A または B … 否定が消えており、まったく別の条件です

迷ったら真理値表を4行書いてください。 A=1, B=0 を入れると、NOT(A かつ B) は 1、②は 0 になり、 違うものだとすぐ分かります。

否定は必ず書き換えてから読んでください。 「〜でないとき」という条件が出てきたら、そのまま考えず、 ド・モルガンで「かつ」と「または」を入れ替えた形に直すのが確実です。 繰り返しを抜ける条件 は、この形で問われることがあります。

ADDER

半加算器：足し算を回路で作る

論理ゲートを組み合わせると、計算そのものが作れます。 いちばん基本になるのが、1桁の2進数どうしを足す半加算器です。

2進数の足し算は4通りしかありません。

計算答え 和 S桁上がり C
0 + 0000
0 + 1110
1 + 0110
1 + 11001

注目したいのはいちばん下の行です。 1 + 1 は2進数では 10 になるので、その桁は 0 になり、1 つ上の桁へ繰り上がります。 この「その桁の値」が和 S、「繰り上がり」が桁上がり C です。

ここで S の列と C の列を、先ほどの真理値表と見比べてください。

  • S の列（0, 1, 1, 0）は XOR とまったく同じ
  • C の列（0, 0, 0, 1）は AND とまったく同じ

つまり足し算は、XOR と AND を1つずつ置くだけで作れます。 上のシミュレーターで「半加算器」を選び、A と B を切り替えて確かめてみてください。

なぜ「半」加算器なのか。 下の桁からの繰り上がりを受け取れないからです。 受け取れるようにしたものを全加算器と呼び、これを桁の数だけ並べると、 何桁でも足せる回路になります。コンピュータの計算は、この積み重ねでできています。

  • OR と XOR の違いが「両方 1 のとき」だと説明できる
